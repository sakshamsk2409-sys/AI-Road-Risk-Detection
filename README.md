\# AI Road Risk Detection



An AI-based road risk and driving behavior detection system designed for Indian road environments.



\## Project Objective



The system analyzes road videos, detects important road objects, extracts 30+ environmental and behavioral features, and uses machine learning to classify the current road risk.



\## Planned Pipeline



Road Video

→ Object Detection

→ Feature Extraction

→ 30+ Feature Dataset

→ Machine Learning

→ Risk Classification

→ Streamlit Visualization



\## Planned Features



\- Vehicle detection

\- Two-wheeler detection

\- Pedestrian detection

\- Animal detection

\- Pothole detection

\- Object distance estimation

\- Object movement

\- Traffic density

\- Road occupancy

\- Heading error

\- Driving behavior indicators

\- Road risk classification



\## Machine Learning



Models to be evaluated:



\- Logistic Regression

\- Random Forest



Evaluation metrics:



\- Accuracy

\- Precision

\- Recall

\- F1-score

\- Confusion Matrix



\## Interface



A Streamlit application will allow users to upload a road video and visualize the AI analysis.
